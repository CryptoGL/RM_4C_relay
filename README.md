# Unit 4Relay for ESP RainMaker

[中文](README_CN.md)

This project connects [ESP RainMaker](https://rainmaker.espressif.com/) to the [M5Stack Unit 4Relay](https://docs.m5stack.com/en/unit/Unit_4Relay), so a phone can provision an ESP32-C3 and control the four relays.

The firmware and the provisioning and usage steps are in [`examples/unit_4relay`](examples/unit_4relay).
