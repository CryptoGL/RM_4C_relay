# 用于 ESP RainMaker 的 Unit 4Relay

[English](README.md)

这个项目把 [ESP RainMaker](https://rainmaker.espressif.com/) 和 [M5Stack Unit 4Relay](https://docs.m5stack.com/en/unit/Unit_4Relay) 接在一起，手机给 ESP32-C3 配网后就能控制四路继电器。

固件，以及配网和使用步骤，在 [`examples/unit_4relay`](examples/unit_4relay)。

- [English](examples/unit_4relay/README.md)
